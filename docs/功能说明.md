# 功能说明（群管业务框架 NoneBot）

> 本项目业务框架与「QQ群管机器人」（NapCat 版）**同一套代码**：因为 SnowLuma 与 NapCat 都说标准 OneBot v11，业务层可以原样复用，所以功能、命令、配置项完全一致。

## 一、功能总览

| 模块 | 文件 | 作用 |
|---|---|---|
| 群管理 | `admin.py` | 禁言 / 解禁 / 踢出 |
| 入群审批 | `approval.py` | 按 QQ 等级自动通过或拒绝入群申请 |
| 黑名单 | `blacklist.py` | 拉黑（踢出+拒绝再入群）/ 解除 / 查看 |
| 违规防护 | `guard.py` | 违禁词与广告正则识别，命中即撤回并禁言 |
| 帮助菜单 | `help.py` | 列出全部命令 |
| 潜水查询 | `inactive.py` | 按 30/60/90 天拉取长期未发言成员 |
| 运行时设置 | `settings.py` | 改等级门槛、广告词、欢迎/退群语、管理群名单 |
| 静默模式 | `silence.py` | 临时全局停摆（风控期自保） |
| 存活检测 | `status.py` | 在线状态与运行时长 |
| 欢迎/退群 | `welcome.py` | 新人欢迎、退群提示 |
| 公共工具 | `common.py` | 管理群校验、静默判定、时长格式化等 |

## 二、命令一览

> ⚠ 所有命令都必须带 `/` 前缀（如 `/禁言`），直接发文字不会触发。

### 群管理（管理员/群主）

| 命令 | 说明 |
|---|---|
| `/禁言 @某人 或 QQ号 [分钟]` | 禁言，默认 10 分钟。例：`/禁言 1000123456 30` |
| `/解禁 @某人 或 QQ号` | 解除禁言 |
| `/踢出 @某人 或 QQ号` | 移出群聊（仅群主） |

### 黑名单（管理员/群主）

| 命令 | 说明 |
|---|---|
| `/拉黑 @某人 或 QQ号 [原因]` | 拉黑并踢出，同时拒绝其再入群 |
| `/解除拉黑 @某人 或 QQ号` | 移出黑名单（别名 `/解黑`、`/移出黑名单`） |
| `/黑名单` | 查看黑名单列表 |

### 自动功能（无需命令）

- **入群审批**：QQ 等级 ≥ 门槛（默认 30 级）自动通过，否则按配置拒绝或忽略
- **广告拦截**：命中广告正则/违禁词 → 撤回消息 + 禁言（默认 1 小时）
- **欢迎/退群提示**：新人入群欢迎、成员退群通知

### 设置（管理员/群主；部分仅私聊超管）

| 命令 | 说明 |
|---|---|
| `/设置等级 30` | 修改入群审批的 QQ 等级门槛 |
| `/添加广告 关键词` / `/删除广告 关键词` | 维护广告拦截规则 |
| `/广告列表` | 查看广告规则与违禁词（别名 `/广告规则`） |
| `/设置欢迎 文本` / `/设置退群 文本` | 修改欢迎语 / 退群提示 |
| `/添加管理群 群号` / `/移除管理群 群号` | 设置生效群（仅私聊，超级管理员） |
| `/管理群列表` | 查看管理群名单 |
| `/静默 2h` | 静默指定时长（支持 `h`/小时、`m`/分钟、`s`/秒），期间对所有群完全静默（仅私聊） |
| `/静默 状态` / `/静默 off` | 查看剩余时间 / 立即解除 |

### 其他

| 命令 | 说明 |
|---|---|
| `/存活` `/ping` `/状态` `/在吗` | 检查在线状态与运行时长 |
| `/菜单` `/help` `/帮助` `/功能` | 显示指令菜单 |
| `/未发言 30\|60\|90` | 拉取超过 N 天未发言的成员名单（默认 30 天；私聊用法：`/未发言 群号 30`） |

## 三、配置项（`qq-group-bot\config.json`）

| 键 | 说明 |
|---|---|
| `managed_groups` | 机器人接管的群号列表，不在名单里的群完全不响应 |
| `admin_users` | 私聊可执行管理命令的 QQ 号 |
| `welcome` / `farewell` | 欢迎/退群文案，支持 `{at}`、`{nickname}` 占位 |
| `auto_approve` | 入群审批：`enabled`、`min_level`（等级门槛）、`groups`（限定群）、`fallback`（不达标时 `ignore`/`reject`）、文案 |
| `banned_words` | 违禁词列表 |
| `ad_patterns` | 广告正则列表 |
| `ad_mute_seconds` / `banned_word_mute_seconds` | 命中后的禁言秒数 |
| `reply_delay` | 回复随机延迟区间（秒），拟人化，避免秒回 |

环境变量（`qq-group-bot\.env`）：

| 键 | 本项目取值 | 说明 |
|---|---|---|
| `HOST` / `PORT` | `127.0.0.1` / **8081** | 业务框架监听地址，必须与 SnowLuma 的 wsClient 地址一致 |
| `SUPERUSERS` | `["1000000001"]` | 超级管理员 QQ 列表 |
| `COMMAND_START` | `["/"]` | 命令前缀，只认 `/命令` |

## 四、本项目与老项目的关系

- **代码同源**：`qq-group-bot\` 是从老项目复制的一份独立副本，两边从此各自演进，改一边不影响另一边
- **运行独立**：本项目跑 8081，老项目跑 8080，可同时运行、互不干扰
- **账号独立**：本项目用哪个号由 `部署配置.json` 的 `snowluma_bot_qq` 决定（用 `切换账号.bat` 维护），
  老项目见它自己的 `部署配置.json`；**同一个号不能同时接两个协议端**
- **功能一致**：本文件列出的命令与老项目完全相同，无需重新学习

## 五、若日后要切换到本项目为主用

1. 停老项目（关它的看门狗窗口），确认旧协议端进程退出
2. 本项目改用目标账号登录：先在桌面版 QQ 里人工换号，再运行 `切换账号.bat list` 确认，用 `switch <QQ>` 让目标账号接管（详见 docs\部署说明.md 第 6 节）
3. 把老项目 `config.json` 中最新的管理群、广告词等设置同步过来
4. 回滚方式：停本项目 → 双击老项目 `启动机器人.bat`
5. ⚠ **收尾必做**：本项目与老项目的账号若相同，把老项目 `部署配置.json` 的 `bot_qq` 改掉或直接停用老项目，
   否则老项目 NapCat 一旦重新登录成功就会与本项目互踢
